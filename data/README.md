# Part 2 — Get an AROME GRIB file

The backend (Part 3) needs a `.grib2` file that contains a **2 m air temperature**
field. You have three options; any one of them satisfies **Checkpoint 2**
(*you have a `.grib2` file and know its path*).

## Way A — file from your instructor (use this in class)
Copy the `.grib2` provided in class somewhere on disk and note its **full path**,
e.g. `/home/you/Downloads/arome_sp1.grib2`. That path is what you pass to the
`load_temperature` command in Part 3/4.

## Way B — download a real AROME SP1 file (recommended, no login)
Run the bundled script — it discovers the **latest run** on the Météo-France
open-data mirror (`files.data.gouv.fr`, 14-day retention) and downloads the
**+00H SP1** file (the initial-analysis snapshot, ~16 MB, real JPEG2000 packing):

```bash
./fetch_arome_sp1.sh
# -> data/arome_sp1_<date>_<hh>Z_00H.grib2
```

Edit `RESOLUTION` at the top of the script to switch between `001` (0.01°,
~1.3 km) and `0025` (0.025°, ~2.5 km). Downloaded files are git-ignored — they
are large and refreshable. See nudibranches-tech/tauri-tp#1 for details.

Other sources: the official portal (free account + token)
<https://portail-api.meteofrance.fr/> or the AWS mirror
<https://mf-models-on-aws.org/> (model `arome-france`).

## Way C — the bundled synthetic sample (offline, used for testing)
`arome_sp1_montpellier_sample.grib2` (~4 KB) is a **small synthetic** GRIB2 field
generated by `make_sample_grib.py`. It is *not* a real Météo-France forecast — it
is a smooth temperature gradient (~13–17 °C) on a 0.025° regular lat/lon grid over
the Montpellier box, encoded exactly like an AROME field for the parts that matter:

| Field                       | Value                                  |
|-----------------------------|----------------------------------------|
| discipline                  | 0 (meteorology)                        |
| parameter category / number | 0 / 0 (temperature)                    |
| first fixed surface         | 103 = height above ground, value **2 m** |
| grid                        | Template 3.0 regular lat/lon, 73 × 49  |
| packing                     | Template 5.0 simple packing (no JPEG2000) |

Because it uses *simple* packing, it decodes with the `grib` crate's default
features — handy when OpenJPEG/JPEG2000 is giving you trouble. Regenerate it with:

```bash
python3 make_sample_grib.py
```

Its path (use this in Part 3/4 while testing):

```
<repo>/grib-map/data/arome_sp1_montpellier_sample.grib2
```
